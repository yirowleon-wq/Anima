# Synthetic campus demonstration

All geometry and labels in this bundle were authored for Anima as a fictional diagram. They do not represent UC Irvine or another real campus. The coordinate frame is WGS84 longitude/latitude and the renderer uses Web Mercator; local profile coordinates use EPSG:3857 meters without a campus-specific offset.

The shared map engine, route topology, entrance selection, access estimates, camera ownership and planar fallback remain usable. Import a separately reviewed map bundle for real navigation. An official map link does not supply redistribution permission. No device location is requested.
