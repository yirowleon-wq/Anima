# Adversarial review of the proposed process

The historical review examined loopholes in this proposal, not an unseen repository. The countermeasures were incorporated into its main plan, method, record guide, rules, phases and rejection card. They preserve useful mechanisms and their limits; none is evidence that Anima's map passed. References to future checker reliability do not authorize new test cases, fixtures or runners.

| Shortcut | Loophole | Countermeasure and decision location |
| --- | --- | --- |
| Create empty documents or fill examples. | File presence is called implementation. | Template-only records count zero; actual IDs, resolvable outputs and current dependencies are required. MAIN, SCHEMA, acceptance gates 1/17. |
| Supply a handful of attractive entities. | Examples imply full-area coverage. | Derive complete source/canonical/generator/candidate sets and reconcile opening/add/remove/closing counts. Q01/Q27. |
| Return empty from every query. | Vacuous all-pass logic. | Scope derives from frozen membership; a known nonempty class needs a real witness. Absence requires complete justified enumeration. Q01/Q26. |
| Say “multiple sources.” | A list substitutes for attribute decisions. | Exact claim locators, candidates, conflicts and adoption/rejection reasons. Family A. |
| Count three copies of one basemap as independent. | URL count substitutes for lineage. | Preserve lineage groups; unknown independence stays unknown. Evidence grade follows applicability, not number of sites. |
| Produce many screenshots. | Repeated region/view masquerades as coverage. | Bind each review to entity/zone/scale/question and actual version. A view proves only its stated observation. Q21/Q27. |
| Run many irrelevant regressions. | Component existence is called map correctness. | Each existing operation must address its failure mode and locate a real defect while discriminating a legitimate witness. Q26/R02. No new tests are authorized here. |

| Count sources and LODs as extra entities. | Completed totals are inflated. | Normalize primary entities; keep missing candidates separate until adjudicated. Method J. |
| Run make-valid everywhere. | Formal validity covers up factual damage. | Compare type, parts, holes and neighbors against sources. Q04/Q06/Q13. |
| Add a layer or bridge flag. | An invented exception suppresses a real collision. | Require a source-backed claim and actual decision; unknown is not legal. Q10/Q11. |
| Delete every intersection. | Strictness destroys real links/boundaries. | Refine by semantics, elevation and representation; courtyards, overhangs and administrative extents have distinct rules. Q11/Q16/Q17. |
| Widen tolerance until it passes. | The gate drifts with results. | Calibrate/freeze before modification; a later change needs new evidence/review and invalidates affected results. Q03/Q07/Q28. |
| Copy old dates or pictures. | A fresh-looking report concerns old inputs. | Bind dependency hashes and integrated commit; mark stale results invalid rather than changing dates. Q24. |
| Each family declares completion. | No single-version spatial acceptance exists. | Scoped MERGE_READY only; integrator deduplicates, checks cross-domain relations and rechecks the candidate. Phase 11. |
| Several writers share a large file. | Worktrees alone fail to prevent overwrite. | One file has one writer; a monolith may require read-only parallel study and serial integration. COMMON. |
| Deliver after a conflict-free Git merge. | Text succeeds while entrances/space conflict. | Recompute applicable integrated relations and revisit affected human scope. Q12/Q17/Q24. |
| Call everything P2 or N_A. | Unresolved defects are renamed nonblocking. | Retain classification/exception history, new evidence and independent judgment; critical doubts cannot be self-approved. Q28/R12. |
| Write that the user accepted. | Acceptance is merely an editable field. | Require actual authority and decision locator/scope. Otherwise state not accepted; implementation submits a candidate. |

## Revisions that the attack produced

Three particularly important clarifications were added: repeated sources and LODs do not add to the entity denominator, while missing candidates have their own accountable set; a filtered-empty scope cannot automatically pass; and a source must locate the specific object evidence rather than merely name an official domain. The seven original image leads were also retained, preventing a four-region outline from silently dropping supplemental problems.

## What prose cannot prevent

A prompt cannot prove that an executor read a source, prevent fabricated check output or guarantee that a client keeps a goal running. A hash proves byte identity, not factual truth. Separate sessions repeating the same mistaken reasoning are not wholly independent review.

Where actually available and authorized, protect criteria/configuration and final acceptance from implementation write access, retain reproducible inputs and real logs, and obtain independent review of key facts, material exceptions and the finished result. Existing CI may re-run an existing check on the same version, but cannot replace source, visual or human acceptance. Lack of this separation is a residual process risk, not something to hide behind a claim that the prompt prevented every shortcut. Current session-recovery rules also remain authoritative; no wait, normal compaction or local tool error can be used to manufacture a failed session or replacement.
