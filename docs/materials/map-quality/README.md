# Map quality working materials

These dated map research and working materials preserve the engineering method, research reasoning, responsibility contracts, twelve map-specific work phases, record formats, rejection procedure and acceptance requirements for Anima. They do not assert that the map has passed those requirements or initiate redevelopment by themselves.

The original research package was version 1.0, dated October 6, 2026. It used seven reported screenshots and a 336-line older instruction document, but did not obtain, run or change the actual map repository, enumerate its objects, measure its geometry or independently survey the site. Historical source reading is reported as such; no later revisit of those references is claimed. Original institutional identities, private places, coordinates, screenshots and geographic datasets are not included here. Anonymous examples preserve a failure mechanism without asserting facts about a replacement campus.

## Preserve three different conclusions

1. **The code runs:** an actual current build opens and its relevant entry points operate. This does not establish correct geography.
2. **Data and declared rules pass on a specified version:** the applicable checks actually ran on an accountable feature set. This still does not establish reality, visual readability or useful navigation.
3. **The stated map scope is accepted:** source, factual, spatial, visual and interaction evidence concerns the same integrated version, and the designated acceptor actually accepts that scope and its disclosed residuals.

An honest blocker or a completed work phase is not whole-map completion. User acceptance is not survey certification. Screenshots, documents, record schemas, output hashes and branch claims cannot substitute for these conclusions.

## Current authority and future work

The original package described six independent project-chat/worktree responsibility families and prohibited subagents in that older setting. Those are historical collaboration assumptions, not current permissions. Current user instructions, Anima's collaboration rules and actual file ownership govern development. Do not open user-owned chats, create teams or execute any map phase merely because this material exists. Do not mistake six domain families for a required headcount; when a formally authorized Anima product stage requires eight substantive roles, that current requirement remains in force.

For future authorized implementation, inventory the actual client and checkout capabilities. Use genuine isolated ownership where available; otherwise use truthful read-only parallel research or serial writing. Never report nonexistent chats, worktrees, reviews or integrations. A source file and a tool that processes it have different responsibilities: raw inputs are evidence candidates; canonical entities hold adopted facts; generators derive display or graphs; independent review evaluates results without silently changing production facts to improve its own pass rate.

Keep OS location services and permissions off on every platform, including emulators and guests. Use lawful imported geometry, manual origins and app-internal virtual coordinates or trajectories. Retain actual source, quality, expiry, unknown, cancellation and recovery states. A simulated position or route does not establish real arrival or official activity credit; an unavailable source is not a reason to invent one.

## Source and completeness

The source package contained 51 files. Its large `COMPLETE_PACKAGE.md` repeated the individual bodies with heading-depth and packaging changes; the maintained individual bodies retain its substantive material. Original checksums identify original bytes only and do not certify changed files.

The historical package did not bundle third-party map tiles, commercial imagery, papers, original screenshots, account data or the actual project repository. A research citation grants no data rights. These materials provide methods for future work, not licensed geographic inputs or evidence that repairs have happened.
