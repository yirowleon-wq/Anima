# Future rejection commission: restore the repair loop

Use this response when factual, spatial or coverage acceptance fails. Preserve current valid work and evidence, withdraw unsupported READY/completion claims and return to the last stage with current-version evidence. Revert only erroneous or unauthorized changes, never erase valid repairs or user work wholesale. More severe prose or more screenshots alone is not a repair.

The integrator supplies applicable rejection codes and exact issue/entity/view. An empty form does not prove no issue; assess the actual submission.
