# Map phase 4: repair by class and shared mechanism

Future material under the [shared phase rules](README.md).

**Entry:** relevant reference passes; clusters, owner, source basis and review method are known; writes are exclusive.

**Work:** fix shared causes and high-risk fact/topology errors before isolated instances. Query every applicable class member per defect. Recheck affected members, neighbors and generated instances after a batch. Hand road/building/ground disputes to integration. Do not record a full workflow per object.

**Outputs:** actual commit/patch, closure evidence, complete applicable-class outcomes, geometric/attribute differences and neighborhood effects.

**Exit:** chosen batch members have fresh outcomes, the original defect is repaired or honestly blocked, no same-level error is introduced and counts/provenance stay complete.

**Do not cross:** fixing only the named object, changing thresholds, moving neighbors to conceal conflict or deleting difficult entities cannot close the batch.

Bind actual members and relevant versions; changes invalidate dependent review.
