# Map phase 2: source and coordinate review

Future material under the [shared phase rules](README.md).

**Entry:** actual baseline denominator, input list, use and AOI exist.

**Work:** check each product's use rights, reference, units, dates, schematic status and precision. Make attribute claims; separate fitting/control and independent check points; freeze conversion chain and error gates. Investigate different dates, roof/ground meanings, repeated lineage and datum error before deciding a conflict.

**Outputs:** sources/claims, alignment configuration, residual report, rights/open-conflict records and one downstream reference version.

**Exit:** each source/object entering repair has a verified chain, critical disputes are decided and independent error meets the use threshold. Unresolved sources remain blocked outside production.

**Do not cross:** do not label all input WGS84, substitute “multiple sources” for judgment or hide per-object offsets. “Reference only” does not permit an unauthorized derivative use.

Bind actual members and all relevant versions; reference changes invalidate dependent conclusions.
