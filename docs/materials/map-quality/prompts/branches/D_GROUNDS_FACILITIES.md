# Family D: sports, grounds, water and vegetation

Read [COMMON](COMMON.md) and the actual contract; this preserved commission grants no extra writes.

## Inputs and exclusive writes

Read facility/natural sources, production generators, source semantics, approved reference/claims and read-only road/building snapshots. Read S18–S21 and Q18–Q19. Do not infer land class from a muted color. Write only assigned ground/sport/water/vegetation data and parameterized generators. Road decks belong to roads; water/shoreline belong here. Do not alter graph, buildings or global tokens; hand conflicting relations to integration.

## Work

Create facility assemblies with boundary, track ring, infield, markings, stands/platform, entrances and connecting spaces, distinguishing required, optional, unknown and inapplicable parts. Apply common rules to comparable tracks, but verify lane count, curvature, infield location, stands and entrances independently. Symmetry is not evidence.

For courts verify sport, number, direction, effective area and surroundings before deriving shared parameterized lines. Standards support templates/plausibility, not site measurement. Review the whole class and scale conditions, preventing one patched field and an omitted neighbor.

Trace ambiguous surfaces to source ID and generator. Distinguish grass, canopy, shrubs, woodland, paving, parking, water, shadow and decoration. Separate water area, bank, channel centerline and island holes. Classify supplemental channel/bridge crossing leads individually. Keep unknowns accountable rather than deleting suspected geography for a cleaner image.

## Required directions and delivery

Q04–Q06, Q17–Q19, Q22, Q24, linking Q10–Q11 for road/bridge conflicts. Deliver composite facilities, class templates and supported parameters, explanations of real differences, semantic mappings, full/sampled memberships and actual outcomes, water/bridge/entrance handoffs and a real patch. Each claim of execution retains scope, feature/location, version and witness; shared IDs and stale dependencies follow COMMON.

## Readiness gate

Common class rules with evidenced differences; every unresolved surface has an explicit disposition; no missing required facility or unknown critical relationship. Copying one field to another, assuming every track has standard dimensions, deleting unnamed surfaces or recoloring instead of identifying prevents readiness. Submit scoped readiness/research/blocker only.
