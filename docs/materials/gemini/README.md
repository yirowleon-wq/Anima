# Character, conversation and initiative

This seven-part design set includes twenty-one life sketches and eleven individual screenshot lessons. It preserves intent, reasons, concrete failures, reading methods and future work. First-person examples illustrate possible experiences; they are not personal history or completed product evidence.

These documents inform development; they do not execute the twelve-stage program, rewrite the whole Harness/OpenUI, create a complete character performance or generate art/video. Choose a substantial work block from the actual current baseline. Publication, account adoption, Memory and real scheduling remain separate choices.

## Choose material for a later block

For character understanding and a serious study/return sequence, read 00, the relevant [character passport](../../characters/README.md), 03 and scenarios 01–10. They explain why a quiet role still needs substantial attention, why a close role can reason carefully, and why a visible selection does not automatically supply a whole original to the model.

For conversational rhythm, use 02's actual assembly/publication map, 01's P5/P6 and scenarios 07–09. Preserve the same primary speaker, real findings, stable published content, interruptible work and the original input/draft. Do not add another model to make an already finished answer sound warm.

For initiative, use 00, 02's full wake/read/prepare/message/notification chain, 03's published inspiration and scenarios 14–20. A real entrustment, selected source/channel, useful preparation, message in its original conversation and honest host lifetime must agree. Chosen relational contact also has a place without becoming unlimited unsolicited work.

For wording and visual refinement, use 01, the individual design notes, scenario 21 and the complete image/spatial/motion methods linked there. Preserve readable original content and working controls. A paper texture, attractive portrait or third-party cat cannot substitute for an actual object, original input or correct source read.

For changes to long-term rules or a work continuation, read 05/06 and the [development roadmap](../../DEVELOPMENT_ROADMAP.md). Existing current contracts remain authoritative. The working bodies are directly readable here.

## Maintenance

Maintain one coherent body per topic here. Shared full methods and character passports keep their own existing maintenance owner and are linked instead of duplicated. A concept appearing both in a letter and an implementation map has a different reading purpose; neither is reduced to an index-only substitute.

Record real new observations where the project already keeps capability/evidence and continuation. This library's completeness does not make the planned character, initiative, notification, whole-cast motion or platform work complete. Preserve each genuine gap and a concrete next entrance.
