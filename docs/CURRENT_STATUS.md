The twelve stage plans and all 38 work blocks now directly include frontend/backend dependencies, GPT Image design or qualified reuse before final affected live interfaces, the Sakiko-first then cast/matrix production order, ordinary acceptance, and exact pause/resume responsibilities. All 200 source questions also have item-specific memory/context acceptance gates and staged scope, with the relevant requirements embedded in the block bodies. This is completed instruction/material work; these new gate records do not claim the future product workflows have passed.

Use Node 24.18.x, npm 11.16.0 and the locked Electron/runtime versions. Follow [installation](../README.md) and [tooling](development/TOOLING.md). The Windows application was built and opened from its own directory. A Mac image workflow has recorded successful serial PNG generation; reference inputs, editing, masks, parallel job identity and Anima's Mac runtime have separate evidence requirements.

UC Irvine and America/Los_Angeles are configurable defaults. Public institutional sources are not private account access, a personal schedule or a licensed redistributable map dataset. Imported files retain their actual source, coverage, revision and permission boundaries. Environmental location is an explicit public reference, separate from device position.

The [project guide](PROJECT_GUIDE.md) maps experiences to existing modules. Installed packages, character resources and upstream attribution support the implementation; their identities and versions remain traceable through the lockfiles.

The proprietary device-discovery branch that had no actual position stream has been removed. Generic external-device contracts and Android, iOS and Windows paths remain. Standard mock/emulator evidence is marked simulated; otherwise unverified Android origin stays unknown, including cadence. The existing Android build entry could not compile because no JDK was available; native compilation and physical-device evidence remain unverified. No device discovery or location sampling was run. For continued development, use app-internal simulated fixes and tracks, manual origins or permitted imports, with provenance and quality preserved. Do not acquire real device location, enable OS location services, or request or grant location permissions on any platform, browser, emulator or guest. Native GPS acquisition is not a current development goal, while map, route, workout and independent native-device work remain in scope.
