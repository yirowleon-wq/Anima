# Continue working on Anima

Anima is a personal project for use, play and continued creation. The [project guide](PROJECT_GUIDE.md) connects the experiences to their real owners and implementation; fictional places, examples and manual records are useful inputs alongside permitted real sources. Install and build as described in the [README](../README.md) before launching.

Current local edition: **Anima 0.3.0, November 1, 2026**. The working materials and retained artwork are available; all formal development stages remain future work. Luna is the normal live model choice, with connection and conversation observations in [current status](CURRENT_STATUS.md). Mac native operation and independent device compilation still need their own platform evidence.

Read [START_HERE](../START_HERE.md), [current evidence](CURRENT_STATUS.md), the [material library](materials/README.md), the [artwork library](../visual-assets/library/README.md), and the [roadmap](DEVELOPMENT_ROADMAP.md). The [work sequence](development/WORK_SEQUENCE.md) organizes substantial blocks with their sources, dependencies, usable results and continuation points. Choose the next block for the current goal and actual workspace conditions.

The next planned entry is the [Stage 00 Swift foundation](development/SWIFT_FOUNDATION_AND_CHARACTER_CONTINUITY.md): migrate the existing desktop experience on the Mac while hardening the single Harness, memory and character participation. The maintainer confirmed macOS desktop first, followed by iPhone/iPad; no native Mac result has been implemented yet. After its exit, the proposed first existing block is the [Sakiko shared-attention commission](stages/01-shared-attention.md). It does not complete the stage, the full character matrix or the replacement runtime. Read the full character passport, presence and motion methods, and original room alternatives before implementation. The other characters, existing capabilities and retained art remain available throughout.

Use the project for study, music, writing, play or rest, and let actual experience guide improvements. An unfinished idea need not become a personal timetable or a debt due today.

When stopping, preserve the actual artifact or object identity and revision, the useful result, known defect or external condition, pending changes, next starting file and the condition for resuming. Keep drafts and source addresses with their owners. Record whether work was proposed, implemented, directly used or accepted. A compact continuation note should make the next session possible without reciting the whole repository.

On return, read that note and the latest files before continuing. Resolve changed objects and permissions; do not restore an old approval, canceled action, stale model run or withdrawn source merely because its intention appears in a note.
