# Optional design studies

These three illustrations are optional composition studies, separate from the [kept original collection](../library/README.md). They do not replace an original, adopt a runtime layout or complete a development stage. Review them against the work at hand before choosing whether to use them.

- [Materials and study](materials-study-v1.png): paired reading and attempt papers with a shared composer.
- [Notes](notes-v1.png): one editable note beside a quietly occupied character.
- [Map](map-v1.png): a fictional synthetic-map composition and a route returning to the conversation. The illustration is not navigation data.

[requests.json](requests.json) records output identities, dimensions, adapted design briefs and the recorded submitted-request hashes separately. The briefs should not be treated as verbatim tool-call transcripts. The internal model version was not recorded. The material/study output includes a subsequent edit to its navigation and unlettered book covers.

Read these as composition studies. Every live text field, source object, program, action and return path must remain a real component and owner state. Preserve the original room/art library and full character passports when choosing a later implementation.
