# Incoming artwork

This is the intake point for additional artwork. No additional collection has been confirmed here.

Preserve originals and their resolution. Give each accepted file a descriptive name, record its SHA-256 and dimensions, inspect the complete image and any visible writing, and describe its intended scene, character, composition and work block. Keep generation prompts only when they are actually available; never infer an exact prompt from the pixels.

Place accepted working materials in the [kept artwork library](../library/README.md), with explicit runtime adoption recorded separately. Keep alternative compositions and unused good originals. A contact sheet can help navigation, but it does not replace the original files or their inspection. Respect explicit retirements and the current character passports.
