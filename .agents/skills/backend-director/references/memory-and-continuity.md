# Evidence memory, conditions and privacy

Inspect the [memory service](../../../../src/main/memory/service.ts), [model](../../../../src/main/memory/model.ts), [repository](../../../../src/main/storage/repository.ts), [context](../../../../src/main/runtime/context.ts), [memory inquiry](../../../../src/main/runtime/memory-inquiry.ts) and its single detailed [prompt](../../../../prompts/memory-inquiry.md).

Memory supports weeks and terms of shared life without flattening someone into labels or repeatedly summarizing summaries until an assistant inference becomes a supposed user fact. “Never doing calculus again” in a passing upset is not a permanent identity; declining one suggestion is not a dislike of an entire activity.

## Six cooperating layers

| Layer | Objects/storage | Authority |
| --- | --- | --- |
| L1 · Original evidence | SourceEvent/EvidenceSpan, h_evidence/h_spans/FTS | Verbatim text, Unicode range, speaker, subject/world/source context, content version and root. Self, third person, fiction and rehearsal remain distinct. |
| L2 · Conditional understanding | Assertion, h_assertions | Understanding anchored in the person's words, with valid/recorded time, ConditionAST, exceptions and independent roots. It can be corrected; it is not the original. |
| L3 · Decisions and friction | DecisionExperience/FrictionHypothesis, h_decisions/h_work | Candidate, actual adoption/refusal, explicit reason and conditions that expire it. “No tablet” can cease to block a library session after a device is borrowed; reopening is not automatic acceptance. |
| L4 · Shared work | Work/Episode/Cooperation and original domain owners | Current matter, study attempts, rehearsal, release drafts and actual help, with generated/rendered/seen/understood/accepted/executed kept distinct. |
| L5 · Domain observations | h_observations and real configured providers | Timetable, exam, grading policy, activity/official recognition, weather/AQI and map facts retain original measures, source, freshness and uncertainty. |
| L6 · Derived addressing | Vectors, entities, retrieval views and context packs | English-appropriate literal/FTS, optional semantic candidates, structures and indexes locate originals. They never become an independent fact authority. Source changes invalidate affected derivatives. |

These are responsibilities, not six competing databases or six model personalities. Notes, original materials, calendar, campus records, character configuration and private understanding retain their own authoritative owners. A style preference stored in localStorage is not user memory or synchronization.

## Two time axes and nine updates

**Valid time** says when a claim applies in life; **recorded time/revision** says when the application learned, changed or archived it. A future move or next-term schedule does not overwrite today. Declared time zone and current source conditions matter.

| Operation | Meaning |
| --- | --- |
| ADD | Introduce an understanding with exact original evidence. |
| SUPPORT | Add genuinely independent source support. Ten summaries of one root still count as one root. |
| REFINE | Add conditions, scope or detail without overturning the meaning. |
| ADD_EXCEPTION | Preserve the underlying pattern and record a dated exception. A wish to rest today does not erase a usual preference for a long study block. |
| SUPERSEDE | Reality changed from a specified effective time. The new norm succeeds the old while its legitimate historical explanation remains. |
| CORRECT | Earlier words or understanding were wrong. Retire the mistaken claim and affected derivatives immediately. |
| DISPUTE | Keep a meaningful unresolved contradiction visible without arbitrarily selecting a source. Clarify when it matters. |
| EXPIRE | End applicability at its validTo or actual closing condition. |
| RETRACT / FORGET | Apply the requested withdrawal/forgetting to its exact original scope and dependent uses through the privacy barrier. |

Understanding can cover twelve content dimensions: academics/deadlines; energy/rhythm; places/commute; environment/sensory preferences; goals/start friction; relationships/boundaries; self-reported wellbeing; financial constraints; temporary exceptions; cooperation preferences such as depth/initiative; historical decisions/refusal reasons; and unresolved ambiguity. These are areas of content, never personality categories that route or restrict the main model.

## Four separate control axes

1. **Read/collect:** which original sources this purpose permits, including the applicable history, user-authored profile, work, local agenda, configured campus source or file.
2. **Transfer/infer:** whether information may leave the device and whether the current words may contribute lasting understanding. local_only is enforced before even a cloud classifier or control parser. An unimplemented local model does not justify a cloud fallback.
3. **Retention:** purpose-scoped retention; history without inference; or session-only memory. Session-only does not write chat history or a consolidation queue and does not persist the protocol chain after the session. Independently authorized calendar/other business work keeps its own valid record.
4. **Audience/action:** private, group and public use differ, as does read versus actual business action. Attachments, tools, websites and role cards are data with no authority to enlarge any axis.

Do not turn one local source restriction into an unexplained ban on every independent source, or treat a request not to read chat as deletion of a separate calendar. Current explicit permission and its exact scope matter.

## Corrections and fences through every outlet

Distinguish ordinary editing, disabling an understanding, withdrawing a proposal, source revocation and permanent forgetting. Current corrections enter usable context promptly; the original reference still checks its version. A normal note revision does not purge independent history. A revoked source or forgetting request updates the real privacy/policy fences and dependencies through SQLite, retrieval, cached packs, drafts, preparation, speech, notifications, exports and reopening. Unaffected source fragments and independent business continue.

At a boundary, discard or revalidate only the affected draft and investigation. Before child delivery and parent adoption, recheck its original source subset: generation under an earlier permission does not authorize present use. A late report, index, cache or old preparation cannot resurrect retired text. A still-lawful published history has its own basis. Do not promise removal from an external recipient or instantaneous physical cleanup on offline devices/backups.

## Retrieval that returns to the original

Default context compilation uses only small justified current anchors, never a large history dump or unverified vector candidates. For an earlier experience, changed habit, unfinished work or exact sentence, use the native bounded memory inquiry/recall entry and its existing pagination/budget.

Combine structured conditions/bitemporal filters, suitable English literal/FTS and entity addressing, optional semantic candidates and original SourceEvent/neighboring-text reading. Confirm negation, irony, speaker, world/rehearsal and temporary conditions in the actual text. No vector resource means honest literal/original fallback, not an empty answer masquerading as “never mentioned.” Index method and language identity must match the installed resource; do not copy an incompatible language assumption or private vectors.

An empty page, truncated read or one missed query does not prove absence. Continue along existing cursors and lawful budget, then tell the primary model the original found, its conditions and remaining unread coverage. The person should not have to manage internal IDs or reading watermarks. Consolidation uses a continuous completed watermark: processed 1,2,4 does not mean processed through 4. Relevant memory should actually change help; unrelated memory should not hijack the current wish.
